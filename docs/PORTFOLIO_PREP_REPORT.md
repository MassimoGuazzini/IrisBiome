# Public portfolio preparation

The original software was copied before changes. The public application is now named IrisBiome and marked `0.9.0.dev0` (portfolio preview).

## Included

- Python/PyQt5 GUI and the existing DADA2 processing script.
- Portable paths, external taxonomy database configuration and configurable CPU usage.
- A public demonstration reporter for abundance summaries, genus-level rarefaction, selected metadata and DOCX/XLSX export.
- Synthetic counts and anamnesis; three arbitrary demo mappings.
- New branding, screenshots and regenerated Italian/English demo reports.

## Excluded

- Real FASTQ, patient metadata, taxonomy databases and runtime logs.
- The complete functional workbook and reference-percentile workbook.
- The private reporter's curated thresholds, interpretation rules and nutritional advice.
- The extended bibliography and explanatory clinical templates.
- Previously generated full reports and workbooks.

Before replacement, a complete private snapshot was saved outside this Git repository. Do not add the backup directory to a public repository.

The DADA2 script was not changed during this public/private separation. Its original attribution remains intact. See [validation](validation.md) for checks and [limitations](limitations.md) for what remains unverified.
