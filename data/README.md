# Demonstration mapping table

`functional_categories.xlsx` contains only the `Demo` sheet with three arbitrary group-to-genus mappings. Columns: `Group`, `Genus`, `Description`.

The genus names are real taxonomic labels used for matching the synthetic example, but the groups A/B/C have no biological functional meaning. There are no clinical ranges, percentiles, treatment suggestions or literature-curated associations here.

The full functional workbook and `summary_table_checked.xlsx` are private and excluded. This public reporter never loads private resources.
